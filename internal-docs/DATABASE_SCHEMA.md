> **Source of truth:** `src/main/database/schema/*.ts` (Drizzle ORM definitions).
> This document is generated by hand from those files and reflects the schema exactly as declared there. No inferred or assumed columns.

- **DBMS:** PostgreSQL
- **ORM:** Drizzle ORM (`drizzle-orm/pg-core`)
- **Default database name:** `turbo_julius` (from `drizzle.config.ts`)
- **Schema entry point:** `src/main/database/schema/index.ts`
- **Migrations output:** `src/main/database/migrations`

**Conventions in this document**
- Types are the PostgreSQL types generated by the Drizzle column builders (`serial` → `serial/integer`, `numeric(p,s)`, `varchar(n)`, `timestamp`, `timestamp with time zone`, `date`, `jsonb`, `boolean`, `text`, `integer`).
- `PK` = primary key, `FK` = foreign key, `UQ` = unique constraint, `NN` = not null.
- Default values are shown as declared. `defaultNow()` maps to `now()`.
